RÚNAKÁRTYÁK – PvP szoba javítás

1. Tedd az index.html, server.js és package.json fájlokat ugyanabba a játékmappába.
2. Ha a játék assetjei az assets mappában vannak, másold az assets mappát is ugyanoda.
3. Telepítés: npm install
4. Indítás: npm start
5. Böngésző: http://localhost:3000

A szerver Socket.IO kapcsolatot használ. A két játékosnak ugyanahhoz a nyilvánosan elérhető szerverhez kell csatlakoznia.
